# 05 · 安全模型

本项目有两条数据面，信任级别不同：

- **原生路径**（Desktop / Android）：内层端到端加密，行星对业务内容零知识。
- **Web 路径**（浏览器）：行星 HTTPS 网关终止 TLS，**行星能看到 Web 明文**。这是有意的信任降级。

## 1. 威胁模型

| 对手 | 能力 | 目标 | 缓解 |
|---|---|---|---|
| 被动网络监听者 | 看流量 | 读取家庭数据 | 原生：TLS + 内层 AEAD；Web：HTTPS |
| 主动网络攻击者 | 篡改/重放/降级 | 冒充、注入 | 签名握手、nonce/计数器、版本协商 |
| 被攻破的行星（原生） | 完全控制中继 | 读取/篡改业务数据 | 端到端加密；行星只见密文 |
| 被攻破的行星（Web） | 完全控制 TLS 终端 | 读取/篡改 Web 数据 | **无法在密码学上阻止**；不记录正文、最小权限、审计、提示信任降级 |
| 局域网内未授权者 | 访问 LAN 服务 | 冒充原生卫星 | 设备密钥 + 配对；LAN 也启用 E2E |
| 丢失/被盗设备 | 持有设备 | 访问家庭数据 | 设备撤销、短会话、设备锁 |
| 被盗 Web Cookie | 持有会话令牌 | 访问 Web | HttpOnly/Secure/SameSite、短 TTL、CSRF、可撤销 |
| Web XSS/CSRF | 注入脚本/伪造请求 | 窃取会话/操作数据 | 固定壳、CSP、严格转义、CSRF token、无第三方脚本 |
| 恶意模块 | 在宿主进程执行代码 | 窃取数据/提权 | 签名+信任库；无沙箱，靠供应链 |
| 供应链攻击 | 替换依赖/产物 | 植入后门 | 版本锁定、哈希、签名、最小依赖；Web 零运行时依赖 |
| 恶意行星 DoS | 断连/丢包/放大 | 可用性 | 多行星、重连、限流、超时 |

**不在范围**：已 root/越狱并被完全控制的卫星、恒星物理访问、国家级别攻击、侧信道。

> **明确不承诺**：Web 路径下「行星零知识」不成立。高敏感数据的上传/导出建议只走原生客户端。

## 2. 身份与密钥

| 身份 | 私钥位置 | 公钥位置 | 用途 |
|---|---|---|---|
| 恒星（签名） | `data/secrets/star.key` | 配对二维码；行星注册表 | 会话签名、模块背书、拓扑签名 |
| 恒星（配对加密） | `data/secrets/star.key` | 配对二维码（`hpk`） | 解密 `PAIR_REQ` |
| 设备（原生卫星） | 设备安全存储 | 恒星 DB（配对时） | 会话签名 |
| 发布者 | 离线/CI | 恒星 `data/trust/publishers/` | 模块签名 |
| 会话临时密钥 | 内存 | 握手交换 | 原生会话加密（用后即弃） |
| Web 用户密码 | 恒星 DB（Argon2id 哈希） | 恒星 DB | Web 登录 |
| Web 会话令牌 | 浏览器 Cookie | 恒星 DB（仅 SHA-256 哈希） | Web 会话认证 |

- 全部使用 Tink 高层原语：
  - 身份签名：Ed25519。
  - 会话密钥封装：HybridEncrypt（X25519 + HKDF + AES-GCM）。
  - 会话加密：AES-256-GCM。
  - KDF：HKDF-SHA256。
- **不手写**分组模式、填充、随机数、密钥派生。
- 长期密钥只签名，不直接加密业务数据。
- Web 密码用 Argon2id 哈希（每个用户独立 salt）；会话令牌 256-bit 随机，DB 只存哈希。
- Web 不做设备配对；身份来自账号密码 + 服务端会话。

### 设备密钥存储

- Android：Tink keyset 由 Android Keystore 的 AES 密钥包裹；优先硬件支持（StrongBox/TEE，若可用）。
- 桌面：优先系统钥匙串（如可用）；否则 `0600` 文件，并提示风险。
- 恒星：`data/secrets/star.key`，`0600`；首次启动生成。

## 3. 配对

1. 恒星生成一次性令牌（随机 16 字节，5 分钟有效，单次使用）与二维码。
2. 二维码含：`homeId`、LAN 地址、行星地址、LAN 证书指纹、恒星 Ed25519 公钥 `pk`、恒星配对加密公钥 `hpk`、令牌。
3. 原生卫星生成设备密钥对；用 `hpk` 加密 `PAIR_REQ { token, devicePub, deviceName, platform, nonce }`，通过 LAN WSS（固定指纹）或行星提交。
4. 恒星用 `hpk` 私钥解密，校验令牌，记录设备公钥；用 `pk` 私钥签名的 `PAIR_OK { homeId, topology, requestHash }` 返回。
5. 原生卫星校验 `PAIR_OK` 签名与 `requestHash`，保存 `homeId`、恒星公钥、证书指纹、拓扑、设备密钥引用。
6. 令牌立即失效；失败尝试计入限流。
7. **Web 不参与配对**：浏览器没有设备密钥；Web 只做账号登录。

安全要点：

- 令牌是 bearer secret；二维码只在可信环境展示。
- **经行星配对也安全**：请求加密到 `hpk`，行星看不到令牌或设备公钥；响应由 `pk` 签名，行星无法伪造/替换。
- 原生卫星必须校验恒星证书指纹（LAN）与 `PAIR_OK` 的恒星签名。
- 配对完成后，后续会话不再依赖令牌；设备公钥成为长期身份。
- 配对使用独立逻辑流；完成后关闭，正常会话重新握手。
- 首次管理员只能由已配对的原生卫星创建；Web 登录在管理员存在后才可用。

## 4. 会话安全

### 4.1 原生会话

详见 [02-protocol.md](02-protocol.md)。

- 双向认证：恒星签名 + 设备签名。
- 前向保密：每次连接新的临时 Hybrid 密钥。
- 重放保护：双方 nonce + 严格递增帧计数器。
- 降级保护：版本取交集，不允许回退到弱参数。
- 会话上限：12h / 2^31 帧 / 8 GiB；到限重新握手。
- 断线不恢复旧会话；重连即新握手。
- 证书固定：LAN 固定指纹；公网行星使用公共 CA 或固定指纹。

### 4.2 Web 会话

- 登录成功后签发 256-bit 随机会话令牌；DB 只存 SHA-256 哈希。
- Cookie：`__Host-homerp_web`，`Secure; HttpOnly; SameSite=Strict; Path=/`。
- CSRF：`__Host-homerp_csrf`（非 HttpOnly）+ `X-CSRF-Token` 双提交；修改类请求强制校验。
- 过期：12h 绝对 + 30min 空闲；滑动续期只延长空闲窗口，不突破绝对上限。
- 撤销：管理员或用户可在「会话」页立即撤销；令牌哈希删除即失效。
- 登录：Argon2id 校验、失败限流与锁定、统一错误文案、可选 TOTP（后续）。
- 行星是 TLS 终端，**能看到密码与 Cookie**；文档与 UI 必须提示这一点。
- Web 会话与原生设备会话分开存储、分开展示。

## 5. 行星的可见性

### 5.1 原生流量

行星可以看到：

- `homeId`、恒星/原生卫星 IP、连接时间、在线状态。
- 外层流 ID、帧大小、方向、时序。
- 握手阶段的公钥、随机数、密文、签名。

行星**不能**看到：

- 内层帧类型、RPC 方法、业务数据、附件内容。
- 用户身份、模块列表、数据库内容。

### 5.2 Web 流量（信任降级）

行星作为 HTTPS 网关，可以看到并修改：

- 请求方法、路径、查询参数、全部请求头与响应头。
- Cookie、会话令牌、登录密码、CSRF token。
- 请求/响应正文、上传/下载内容。

因此：

- 行星**必须**配置为不记录请求/响应体、Cookie、Authorization；访问日志只保留聚合指标。
- 行星不得缓存 API 响应；静态资源可缓存。
- 行星被攻破时，Web 数据与 Web 会话会暴露；原生流量仍安全。
- UI 在 Web 登录/设置页显著提示「Web 经行星网关，行星可见明文」。
- 高敏感操作（备份导出、模块安装、设备撤销）建议使用原生客户端，或要求 Web 重新认证。

可选增强（后续）：

- 原生：填充帧到固定大小，降低流量分析。
- 原生：恒星↔行星之间使用固定指纹 + 双向认证。
- 行星：不记录连接日志（或仅保留聚合指标）。
- Web：端到端加密的 Web 客户端（需要浏览器侧密钥管理，复杂度高，暂不做）。

## 6. 授权

### 账号与角色

- `members` 模块管理家庭成员；`auth` 模块管理登录与角色。
- 角色示例：`admin`、`member`、`guest`、`child`。
- 权限：`<module>.<resource>.<action>`。
- 默认拒绝；RPC 必须声明权限或 `public`。

### 设备与用户

- 原生设备是「谁能连接」；用户是「能做什么」。
- 一个设备可登录不同用户；会话中包含设备 ID + 用户 ID。
- 管理员可撤销设备；撤销后新握手失败，已有会话在下次重连时失效（可选主动 `GOAWAY`）。
- Web 会话也出现在「会话/设备」页，显示为 `web` 类型；可单独撤销。
- Web 用户与原生用户共享账号、角色、权限；Web 不是额外权限来源。
- 高敏感操作（模块安装、设备撤销、备份导出）要求 `admin` + 重新认证（后续）；Web 端同样适用。

### 首次启动

- 恒星首次启动进入「待配对」状态，只接受配对请求与最小管理接口。
- 第一个注册账号成为管理员；账号注册与管理员引导只允许来自**已配对原生设备**。
- 配对令牌与管理员引导都需在本地/可信环境完成；Web 不能完成首次引导。
- LAN 证书轮换通过已配对会话推送新指纹；无法推送时要求重新配对。

## 7. 模块供应链

- 模块必须由受信任发布者签名；恒星安装前校验：
  1. `manifest.json` 原始字节哈希。
  2. 每个产物的 SHA-256。
  3. Ed25519 签名与 `keyId`。
  4. 发布者公钥在信任库中。
  5. API / Compose 版本兼容。
  6. 依赖图完整、无环。
- 卫星加载前校验：
  1. 恒星对模块的背书签名（`ModuleAttestation`）。
  2. 产物哈希。
  3. API / Compose 兼容。
- 失败即拒绝，不执行任何模块代码。
- `developerMode` 允许未签名模块，但：
  - 仅限本机/受控环境。
  - UI 明确标识「未验证」。
  - 发布构建默认关闭。
- Web 壳不参与模块供应链：它由宿主源码构建、随恒星分发、无运行时第三方依赖；`typescript` 仅构建期依赖并锁定版本。
- Web 壳不加载 `.hmod`，因此模块签名/背书不适用于 Web UI。

### 撤销与升级

- 发布者密钥泄露：从信任库移除 → 新安装拒绝；已安装模块标记为不可信，建议停用。
- 模块漏洞：恒星可远程停用模块（管理员操作）；卫星收到拓扑/模块状态后卸载或禁用。
- 升级保留旧版本包，支持回滚；回滚不降级数据库（只允许向前迁移）。

## 8. Android 动态代码的特殊风险

- 动态 DEX 加载绕过应用商店审核；本项目通过自有渠道分发。
- 模块代码与宿主同进程、同权限，**没有沙箱**；只能安装可信模块。
- 模块可访问宿主内存中的会话与数据；无法从技术上完全阻止，依赖签名与代码评审。
- ART 无法卸载已加载类；卸载后代码仍在内存直到进程结束。
- Android 14+ 对动态加载文件有只读要求；使用 `InMemoryDexClassLoader` 规避可写文件执行限制。
- Google Play 政策限制动态代码加载；若上架 Play，改用 Play Feature Delivery 或放弃动态 UI。
- 模块不得包含原生库（v1），降低 ABI/加载风险。
- Web 端不加载动态代码，不受本节风险影响；代价是没有模块自定义 Web UI。

## 9. 机密管理

- 恒星主密钥：`data/secrets/master.key`，`0600`，首次启动生成。
- 模块敏感配置：用主密钥派生的 AES-GCM 密钥加密后存 DB。
- 设备私钥：只在设备；恒星不接收。
- 发布者私钥：绝不入库；CI 用 org secrets，离线发布用硬件/加密存储。
- Web 密码：只存 Argon2id 哈希；不存明文、不写日志。
- Web 会话令牌：只存 SHA-256 哈希；Cookie 值不写日志。
- 日志禁止打印：token、私钥、会话密钥、密码、完整附件内容。
- 崩溃报告默认关闭；如需开启，先脱敏。

## 10. 网络加固

- 仅 TLS 1.3（或 1.2+ 强套件）；禁用明文与弱套件。
- 证书固定：LAN 恒星证书；行星可固定或使用公共 CA。
- 连接限流：按 IP / `homeId` / 设备。
- 握手超时 10s；空闲 60s 断开；最大帧 64 KiB；最大并发流 64。
- 行星不开放业务端口给公网；只开放 WSS 与 HTTPS（Web 网关）。
- 恒星不开放公网入站；只主动拨出。
- 拒绝未知 `homeId`、未知设备、过期令牌。
- 防放大：`OPEN_REJECT` 不回显大负载；限制错误响应大小。
- Web 网关：HSTS、TLS 1.2+ 强套件、请求头 ≤ 32 KiB、请求体流式 ≤ 2 GiB、按 IP/`homeId` 限流。
- Web 网关不是开放代理：只路由已注册 `homeId`；未知 home 返回通用 404。
- 恒星 Web 适配器只接受来自行星隧道的 `WEB_HTTP` 流，不监听 LAN/公网端口。
- Web 响应头：CSP、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy`、`X-Frame-Options: DENY`。
- API 响应 `Cache-Control: no-store`；静态资源按内容哈希缓存。

## 11. 审计

记录（本地 DB/日志，管理员可查）：

- 配对成功/失败、设备撤销。
- 原生登录成功/失败、权限拒绝（采样）。
- Web 登录成功/失败、Web 会话创建/撤销、CSRF 校验失败、登录限流触发。
- 模块安装/升级/卸载/启用/禁用、签名校验失败。
- 备份/恢复、导出。
- 管理员敏感操作。

审计日志不含业务数据正文、Cookie、密码、请求体；保留期可配置。卫星侧记录模块安装与连接切换。行星只保留聚合指标，不记录 Web 正文。

---

## 12. 备份安全

- 备份包含全部家庭数据，按最高敏感级别保护。
- 建议备份到加密磁盘；可选对备份做 age/GPG 加密（后续）。
- 备份目录权限 `0700`；不在日志中输出路径以外的内容。
- 恢复前校验清单与哈希；拒绝损坏/不完整备份。
- Web 会话表默认不备份；恢复后所有 Web 会话失效，需重新登录。

---

## 13. 依赖与供应链

- 版本在 `libs.versions.toml` 锁定；禁止动态版本。
- 校验依赖哈希（Gradle dependency verification，后续启用）。
- 优先 JetBrains/Google/Apache 维护的库；减少传递依赖。
- 定期升级；关注 Tink/Ktor/Compose 安全公告。
- 构建可复现：固定 JDK、Gradle、依赖版本；记录构建环境。
- Web 壳无运行时依赖；`typescript` 锁定版本，构建产物哈希入库/随版本发布。
- Web 壳不使用 CDN、第三方字体、分析脚本；所有资源同源并由恒星提供。
