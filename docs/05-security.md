# 05 · 安全模型

## 1. 威胁模型

| 对手 | 能力 | 目标 | 缓解 |
|---|---|---|---|
| 被动网络监听者 | 看流量 | 读取家庭数据 | 外层 TLS + 内层 AEAD |
| 主动网络攻击者 | 篡改/重放/降级 | 冒充、注入 | 签名握手、nonce/计数器、版本协商 |
| 被攻破的行星 | 完全控制中继 | 读取/篡改业务数据 | 端到端加密；行星只见密文 |
| 局域网内未授权者 | 访问 LAN 服务 | 冒充卫星 | 设备密钥 + 配对；LAN 也启用 E2E |
| 丢失/被盗设备 | 持有设备 | 访问家庭数据 | 设备撤销、短会话、设备锁 |
| 恶意模块 | 在宿主进程执行代码 | 窃取数据/提权 | 签名+信任库；无沙箱，靠供应链 |
| 供应链攻击 | 替换依赖/产物 | 植入后门 | 版本锁定、哈希、签名、最小依赖 |
| 恶意行星 DoS | 断连/丢包/放大 | 可用性 | 多行星、重连、限流、超时 |

**不在范围**：已 root/越狱并被完全控制的卫星、恒星物理访问、国家级别攻击、侧信道。

---

## 2. 身份与密钥

| 身份 | 私钥位置 | 公钥位置 | 用途 |
|---|---|---|---|
| 恒星（签名） | `data/secrets/star.key` | 配对二维码；行星注册表 | 会话签名、模块背书、拓扑签名 |
| 恒星（配对加密） | `data/secrets/star.key` | 配对二维码（`hpk`） | 解密 `PAIR_REQ` |
| 设备（卫星） | 设备安全存储 | 恒星 DB（配对时） | 会话签名 |
| 发布者 | 离线/CI | 恒星 `data/trust/publishers/` | 模块签名 |
| 会话临时密钥 | 内存 | 握手交换 | 会话加密（用后即弃） |

- 全部使用 Tink 高层原语：
  - 身份签名：Ed25519。
  - 会话密钥封装：HybridEncrypt（X25519 + HKDF + AES-GCM）。
  - 会话加密：AES-256-GCM。
  - KDF：HKDF-SHA256。
- **不手写**分组模式、填充、随机数、密钥派生。
- 长期密钥只签名，不直接加密业务数据。

### 设备密钥存储

- Android：Tink keyset 由 Android Keystore 的 AES 密钥包裹；优先硬件支持（StrongBox/TEE，若可用）。
- 桌面：优先系统钥匙串（如可用）；否则 `0600` 文件，并提示风险。
- 恒星：`data/secrets/star.key`，`0600`；首次启动生成。

## 3. 配对

1. 恒星生成一次性令牌（随机 16 字节，5 分钟有效，单次使用）与二维码。
2. 二维码含：`homeId`、LAN 地址、行星地址、LAN 证书指纹、恒星 Ed25519 公钥 `pk`、恒星配对加密公钥 `hpk`、令牌。
3. 卫星生成设备密钥对；用 `hpk` 加密 `PAIR_REQ { token, devicePub, deviceName, platform, nonce }`，通过 LAN WSS（固定指纹）或行星提交。
4. 恒星用 `hpk` 私钥解密，校验令牌，记录设备公钥；用 `pk` 私钥签名的 `PAIR_OK { homeId, topology, requestHash }` 返回。
5. 卫星校验 `PAIR_OK` 签名与 `requestHash`，保存 `homeId`、恒星公钥、证书指纹、拓扑、设备密钥引用。
6. 令牌立即失效；失败尝试计入限流。

安全要点：

- 令牌是 bearer secret；二维码只在可信环境展示。
- **经行星配对也安全**：请求加密到 `hpk`，行星看不到令牌或设备公钥；响应由 `pk` 签名，行星无法伪造/替换。
- 卫星必须校验恒星证书指纹（LAN）与 `PAIR_OK` 的恒星签名。
- 配对完成后，后续会话不再依赖令牌；设备公钥成为长期身份。
- 配对使用独立逻辑流；完成后关闭，正常会话重新握手。

## 4. 会话安全

详见 [02-protocol.md](02-protocol.md)。

- 双向认证：恒星签名 + 设备签名。
- 前向保密：每次连接新的临时 Hybrid 密钥。
- 重放保护：双方 nonce + 严格递增帧计数器。
- 降级保护：版本取交集，不允许回退到弱参数。
- 会话上限：12h / 2^31 帧 / 8 GiB；到限重新握手。
- 断线不恢复旧会话；重连即新握手。
- 证书固定：LAN 固定指纹；公网行星使用公共 CA 或固定指纹。

## 5. 行星的可见性

行星可以看到：

- `homeId`、恒星/卫星 IP、连接时间、在线状态。
- 外层流 ID、帧大小、方向、时序。
- 握手阶段的公钥、随机数、密文、签名。

行星**不能**看到：

- 内层帧类型、RPC 方法、业务数据、附件内容。
- 用户身份、模块列表、数据库内容。

可选增强（后续）：

- 填充帧到固定大小，降低流量分析。
- 恒星↔行星之间使用固定指纹 + 双向认证。
- 行星不记录连接日志（或仅保留聚合指标）。

## 6. 授权

### 账号与角色

- `members` 模块管理家庭成员；`auth` 模块管理登录与角色。
- 角色示例：`admin`、`member`、`guest`、`child`。
- 权限：`<module>.<resource>.<action>`。
- 默认拒绝；RPC 必须声明权限或 `public`。

### 设备与用户

- 设备是「谁能连接」；用户是「能做什么」。
- 一个设备可登录不同用户；会话中包含设备 ID + 用户 ID。
- 管理员可撤销设备；撤销后新握手失败，已有会话在下次重连时失效（可选主动 `GOAWAY`）。
- 高敏感操作（模块安装、设备撤销、备份导出）要求 `admin` + 重新认证（后续）。

### 首次启动

- 恒星首次启动进入「待配对」状态，只接受配对请求与最小管理接口。
- 第一个注册账号成为管理员；账号注册与管理员引导只允许来自**已配对设备**。
- 配对令牌与管理员引导都需在本地/可信环境完成。
- LAN 证书轮换通过已配对会话推送新指纹；无法推送时要求重新配对。

## 7. 模块供应链

- 模块必须由受信任发布者签名；恒星安装前校验：
  1. `manifest.json` 原始字节哈希。
  2. 每个产物的 SHA-256。
  3. Ed25519 签名与 `keyId`。
  4. 发布者公钥在信任库中。
  5. API / Compose 版本兼容。
  6. 依赖图完整、无环。
- 卫星加载前校验：
  1. 恒星对模块的背书签名（`ModuleAttestation`）。
  2. 产物哈希。
  3. API / Compose 兼容。
- 失败即拒绝，不执行任何模块代码。
- `developerMode` 允许未签名模块，但：
  - 仅限本机/受控环境。
  - UI 明确标识「未验证」。
  - 发布构建默认关闭。

### 撤销与升级

- 发布者密钥泄露：从信任库移除 → 新安装拒绝；已安装模块标记为不可信，建议停用。
- 模块漏洞：恒星可远程停用模块（管理员操作）；卫星收到拓扑/模块状态后卸载或禁用。
- 升级保留旧版本包，支持回滚；回滚不降级数据库（只允许向前迁移）。

## 8. Android 动态代码的特殊风险

- 动态 DEX 加载绕过应用商店审核；本项目通过自有渠道分发。
- 模块代码与宿主同进程、同权限，**没有沙箱**；只能安装可信模块。
- 模块可访问宿主内存中的会话与数据；无法从技术上完全阻止，依赖签名与代码评审。
- ART 无法卸载已加载类；卸载后代码仍在内存直到进程结束。
- Android 14+ 对动态加载文件有只读要求；使用 `InMemoryDexClassLoader` 规避可写文件执行限制。
- Google Play 政策限制动态代码加载；若上架 Play，改用 Play Feature Delivery 或放弃动态 UI。
- 模块不得包含原生库（v1），降低 ABI/加载风险。

## 9. 机密管理

- 恒星主密钥：`data/secrets/master.key`，`0600`，首次启动生成。
- 模块敏感配置：用主密钥派生的 AES-GCM 密钥加密后存 DB。
- 设备私钥：只在设备；恒星不接收。
- 发布者私钥：绝不入库；CI 用 org secrets，离线发布用硬件/加密存储。
- 日志禁止打印：token、私钥、会话密钥、密码、完整附件内容。
- 崩溃报告默认关闭；如需开启，先脱敏。

---

## 10. 网络加固

- 仅 TLS 1.3（或 1.2+ 强套件）；禁用明文与弱套件。
- 证书固定：LAN 恒星证书；行星可固定或使用公共 CA。
- 连接限流：按 IP / `homeId` / 设备。
- 握手超时 10s；空闲 60s 断开；最大帧 64 KiB；最大并发流 64。
- 行星不开放业务端口给公网；只开放 WSS。
- 恒星不开放公网入站；只主动拨出。
- 拒绝未知 `homeId`、未知设备、过期令牌。
- 防放大：`OPEN_REJECT` 不回显大负载；限制错误响应大小。

## 11. 审计

记录（本地 DB/日志，管理员可查）：

- 配对成功/失败、设备撤销。
- 登录成功/失败、权限拒绝（采样）。
- 模块安装/升级/卸载/启用/禁用、签名校验失败。
- 备份/恢复、导出。
- 管理员敏感操作。

审计日志不含业务数据正文；保留期可配置。卫星侧记录模块安装与连接切换。

---

## 12. 备份安全

- 备份包含全部家庭数据，按最高敏感级别保护。
- 建议备份到加密磁盘；可选对备份做 age/GPG 加密（后续）。
- 备份目录权限 `0700`；不在日志中输出路径以外的内容。
- 恢复前校验清单与哈希；拒绝损坏/不完整备份。

---

## 13. 依赖与供应链

- 版本在 `libs.versions.toml` 锁定；禁止动态版本。
- 校验依赖哈希（Gradle dependency verification，后续启用）。
- 优先 JetBrains/Google/Apache 维护的库；减少传递依赖。
- 定期升级；关注 Tink/Ktor/Compose 安全公告。
- 构建可复现：固定 JDK、Gradle、依赖版本；记录构建环境。
