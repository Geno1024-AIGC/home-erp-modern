# 06 · 路线图

## 原则

- **先验证风险，再堆功能**。协议、动态加载、中继背压各有一个时间盒 spike。
- 每个里程碑可独立验收；未通过不进入下一个。
- 模块 API 从 M1 起冻结主版本；后续只做兼容新增。
- 文档与测试随代码提交，不后补。

---

## M0 · 仓库与构建基线

**交付**

- Gradle Wrapper 9.7.1、`settings.gradle.kts`、根 `build.gradle.kts`。
- `build-logic` convention plugins（JVM、KMP、Compose、Android、模块打包）。
- `gradle/libs.versions.toml` 锁定 Kotlin/Compose/Ktor/Tink/SQLite 版本。
- `.gitignore`、`README.md`、`docs/`。
- CI：`./gradlew build` + 测试；不发布。

**验收**

- `./gradlew build` 在干净环境通过。
- `./gradlew projects` 结构符合 [01-architecture.md](01-architecture.md)。
- 无密钥/构建产物入库。

---

## M1 · 协议与会话（先做 spike）

**Spike（时间盒 1–2 周）**

1. 外层帧编解码 + 内存中继（行星只转发 `DATA`）。
2. 内层握手（Tink Ed25519 + HybridEncrypt + HKDF + AES-GCM）。
3. 多路复用 + 窗口流控 + 大文件传输不饿死小 RPC。
4. Android 与 JVM 两端 Tink 行为一致。

**交付**

- `core:protocol`：帧、流、握手、会话、RPC 编解码。
- 进程内 harness：恒星 + 行星 + 卫星，直连/中继两种路径。
- 协议一致性测试与负例。

**验收**

- 卫星经行星完成 RPC 与 1 GiB 流式上传；行星侧抓包无法解出内容。
- 握手失败、签名错误、重放、版本不匹配均被拒绝。
- 断线重连、上传续传、流控阻塞测试通过。
- 64 并发小 RPC + 1 个大上传，小 RPC P99 不受明显影响。

---

## M2 · 恒星数据层与核心模块

**交付**

- `star` 应用：配置、日志、WSS 服务端、行星拨出、配对、拓扑。
- SQLite `Db`、迁移、附件库、备份/恢复 CLI。
- `core:star-api`：`StarModule`、`StarContext`、`RpcRegistry`、权限。
- 核心模块：`members`、`auth`（账号、角色、设备）。
- 首个业务模块：`inventory` 服务端（CRUD + 附件）。

**验收**

- 首次启动引导管理员；配对设备；登录。
- 迁移可重复执行；失败回滚；校验和检测篡改。
- 附件上传/下载/去重/GC；备份恢复后数据一致。
- 权限拒绝返回正确状态码；审计记录关键操作。

---

## M3 · 桌面卫星与动态模块

**交付**

- `satellite:shared`：会话、连接选择、RPC 客户端、模块管理、设计系统。
- `satellite:desktop`：Compose Desktop 壳、配对、登录、导航。
- `core:client-api` + `core:ui`。
- `tools/hmod`：打包、签名、校验、生成 `.hmod`。
- 桌面动态加载：`URLClassLoader` + 模块 UI 注册。

**验收**

- 安装签名的 `inventory.hmod` → 侧边栏出现入口 → 增删改查可用。
- 卸载后入口消失；重启后类彻底释放。
- 未签名/哈希错误/API 不兼容模块被拒绝。
- 模块升级后可切换；失败可回滚。

---

## M4 · Android 卫星与动态 DEX

**交付**

- `satellite:android`：Compose 壳、配对、登录、导航、模块管理。
- `InMemoryDexClassLoader` 加载模块 DEX。
- 平台能力：扫码、文件选择、通知。
- Android 签名接入 org keystore（见上级 `RULES/KEYSTORE.md`）。
- `d8` 打包流程与兼容性校验。

**验收**

- 同一 `inventory.hmod` 在 Android 上安装并渲染。
- 升级提示重启；重启后加载新 DEX；卸载后入口消失。
- API 26/33/36 至少各一台设备/模拟器验证。
- release APK 使用 org keystore 签名；未配置时明确失败/不发布。

---

## M5 · 行星部署与远程访问

**交付**

- `planet` 应用：WSS 中继、home 注册表、限流、指标、优雅关闭。
- 恒星多行星拨出与拓扑推送。
- 卫星连接选择：LAN 优先、行星 RTT 选择、失败回退。
- 部署文档：systemd、TLS 证书、防火墙、日志轮转。
- 运维：健康检查、备份、升级。

**验收**

- 家中卫星直连；外地卫星经行星访问；切换无需手动改地址。
- 断开一个行星后自动切到另一个；恢复后回归。
- 行星重启后恒星/卫星自动重连。
- 行星无法读取业务数据（抓包/日志验证）。

---

## M6 · 模块管理、签名与发布

**交付**

- 恒星管理 RPC/CLI：安装、启用、禁用、升级、回滚、删除、信任库。
- 卫星模块管理器：安装、更新、卸载、版本与来源展示。
- 恒星背书（`ModuleAttestation`）与卫星校验。
- `hmod` 发布流程：构建、签名、哈希清单、公钥指纹。
- 审计与失败告警。

**验收**

- 未签名模块在发布模式被拒绝；`developerMode` 下可用且有醒目标识。
- 撤销发布者后新安装被拒绝；已安装模块被标记。
- 升级/回滚保留数据；删除数据需二次确认。

---

## M7 · 业务模块

按用户优先级：

1. `inventory`（存货/物资：库位、数量、保质期、出入库、购物清单）
2. `tasks`（家务/任务：周期任务、分派、提醒）
3. `assets`（家庭资产/设备：保修、维护记录）
4. `documents`（文档/凭证：扫描、归档、关联）

每个模块：

- 服务端：迁移、RPC、权限、事件。
- 客户端：导航页、列表/详情/编辑、离线错误处理。
- 测试：迁移、权限、关键流程。
- README：数据模型与 RPC 列表。

**验收**

- 每个模块可独立安装/卸载，不破坏其他模块。
- 权限模型符合预期；普通成员/管理员差异可见。
- 关键流程有端到端测试。

## 后续（v1 之后）

- 离线缓存与乐观更新（非 CRDT 起步）。
- 多家庭 / 多恒星。
- 浏览器卫星或 Web 管理台。
- 备份加密、异地备份。
- 全文搜索跨模块聚合。
- 通知推送（行星不参与内容）。
- 模块市场/仓库（签名、评分、更新源）。
- 可观测性：指标、追踪（脱敏）。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| Android 动态 DEX 不可行/受限 | 客户端动态 UI 失败 | M1 前 spike；备选 Play Feature Delivery 或内置模块 + 服务端驱动 UI |
| 自定义握手漏洞 | 数据泄露/冒充 | Tink 原语；负例测试；外部评审；先做协议冻结 |
| Compose 版本耦合 | 模块加载崩溃 | 清单声明 Compose 版本；宿主校验；模块随宿主重编 |
| 中继背压/公平性 | 大文件卡死交互 | 双层窗口；M1 压测；每流上限 |
| SQLite 写阻塞 | 卡顿/超时 | 短事务；读写连接分离；慢查询日志 |
| 模块 API 破坏 | 第三方模块失效 | M1 冻结主版本；兼容新增；弃用周期 |
| 行星被 DDoS | 远程不可用 | 多行星；限流；云防火墙；不暴露恒星 |
| 设备丢失 | 数据泄露 | 设备撤销；短会话；设备锁；审计 |

## 开放问题

1. Android `applicationId` 是否与旧版共存（影响升级路径与签名）。
2. 是否需要在 v1 支持浏览器卫星。
3. 备份是否需要默认加密。
4. 模块市场是否需要中心化索引（以及行星是否参与）。
5. 多用户并发写入的预期规模（决定 SQLite 连接池与 WAL 策略）。
